## Start of every session
1. Read `decisions.md`, then `open-questions.md`, then `ideas.md`.
2. Read the latest file in `journal/`.
3. Don't contradict `decisions.md` without flagging it first.

## Working rules
- `decisions.md`: append dated entries, never rewrite history. When an open question is settled, move it here and remove it from `open-questions.md`.
- `ideas.md`: keep ideas grouped; mark held, dropped or in-progress items instead of deleting them.
- `journal/YYYY-MM-DD.md`: one short file per working day. What was discussed, what changed, what's next.
- Before ending a session, update the journal and decisions, then commit with one topic per commit.
